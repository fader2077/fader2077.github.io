# Architecture

The portfolio is a static Astro site. Astro content collections validate project and publication Markdown at build time. Small YAML files hold profile, navigation, homepage composition, CV, and SEO data. The homepage section registry is deliberately closed: a configured `type` must exist in `src/lib/section-registry.ts`, otherwise validation fails.

Decap CMS is an editing surface, not a runtime dependency. It commits content through GitHub; every production page is generated by Astro and deployed as static files. No credential or CMS token is stored in this repository.

Legacy public paths remain stable: `/`, `/projects.html`, `/publications.html`, `/cv.html`, and `/404.html`. Project case studies use `/projects/<slug>/`.

Content visibility is fail-closed. Draft, private, and confidential projects are excluded from public lists and generated routes. Publication totals count only records marked verified and in a formal result status.
