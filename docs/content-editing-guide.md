# Content editing guide

Use `/admin/` or edit Markdown/YAML directly. Save new work as a draft first. Before publishing:

- confirm every link is real and HTTPS;
- keep private or confidential projects non-public;
- attach evidence to every numeric metric;
- verify publication metadata against a DOI registry, proceedings, or publisher page;
- use an existing homepage section type;
- preview the pull request and wait for validation.

Do not add placeholder links, invented claims, percentage skill scores, or secrets. Uploads belong in `public/uploads`; downloadable documents belong in `public/documents`.

`private` and `confidential` only suppress generated site routes. This repository, its branches, pull requests, and history are public, so never commit sensitive material.
